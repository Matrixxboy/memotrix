# API Reference: The `Memory` Facade

The `Memory` class is the primary entry point for the Memotrix SDK. It acts as a facade, orchestrating the extraction, ingestion, vector stores, and retrieval pipelines.

```python
from memotrix import Memory
```

## Initialization

```python
Memory(
    embeddings: Embeddings, 
    store: VectorStoreBundle = None,
    backend: str = "memory",
    connection: str = None,
    extract_file: Callable = None
)
```

**Parameters:**
- `embeddings` (Embeddings): An instance of `Embeddings` (e.g. `HuggingFaceEmbeddings`). You can also pass a model string, which will be coerced into a HuggingFace model.
- `store` (VectorStoreBundle): Optional. A pre-configured vector store (like `PostgresStore`).
- `backend` (str): `"memory"` or `"postgres"`. Defaults to `"memory"`.
- `connection` (str): Optional. A database connection string. If provided, `backend` is forced to `"postgres"`.
- `extract_file` (Callable): Optional. A custom router function to bypass the default file extractors.

### Alternate Constructors
- `Memory.from_config(config: MemoryConfig, embeddings=None)`: Instantiates from a configuration object.
- `Memory.from_env(embeddings=None)`: Instantiates entirely using environment variables (e.g., `DATABASE_URL`, `EMBEDDING_MODEL`).

---

## Methods

### `add(path: str | Path, **kwargs) -> dict`
Ingests a file into memory. The file is extracted, chunked, embedded, and inserted into both dense and sparse indexes.

**Arguments:**
- `path`: The absolute or relative path to the file.
- `describe_images` (bool): Defaults to True. If False, vision captioning for images is skipped.
- `generate_srt` (bool): Defaults to False. If True, audio/video extractors will dump an SRT file alongside the source.

**Returns:**
A dictionary containing ingestion statistics:
`{"filename": str, "source_path": str, "chunks": int, "inserted": int, "merged": int, "extracted_images": int}`

### `add_text(text: str, **kwargs) -> dict`
Ingests raw text directly into memory without a file.

**Arguments:**
- `text`: The string to ingest.
- `source_id`: A unique identifier for this text. If omitted, a UUID is generated.
- `memory_type`: Defaults to `"semantic"`. Can be set to `"episodic"` or `"procedural"`.
- `session_id`: Optional string to tag the text to a specific conversation or session.
- `metadata`: Optional dictionary of extra JSON fields to store in the payload.

### `add_documents(documents: List, **kwargs) -> dict`
Ingests a list of pre-extracted `DocumentData` objects. This bypasses the extraction step entirely.

### `search(query: str, **kwargs) -> List[dict]`
Performs a hybrid search against the memory using the provided query string.

**Arguments:**
- `query`: The search string.
- `top_k` (int): Number of results to return. Defaults to `RetrievalConfig.top_k` (3).
- `max_tokens_returned` (int): A soft limit on the total size of the expanded chunks. Defaults to 800.
- `filters` (dict): A dictionary of exact-match filters (e.g. `{"department": "DevOps"}`).
- `session_id` (str): Convenience argument that is merged into `filters`.
- `memory_type` (str): Convenience argument that is merged into `filters`.
- `expand_mode` (str): `"neighbors"`, `"full_file"`, or `"none"`.

**Returns:**
A list of dictionaries. Each dictionary represents a Hit, containing the `chunk_text`, `score`, and payload metadata.

### `delete(source_ref: str) -> int`
Deletes all chunks, vectors, and DocumentStore adjacencies associated with a given source.

**Arguments:**
- `source_ref`: Can be the absolute `source_path`, the basename `filename`, or the `source_id` generated by `add_text()`.

**Returns:**
The number of rows deleted from the index.

### `extract(path: str | Path, **kwargs) -> DocumentData`
Extracts a file using the Memotrix extractors and returns the parsed `DocumentData` object **without** chunking or indexing it. Useful for debugging or custom ETL pipelines.

### `close()`
Closes any active database connections (like Postgres pools). Should be called when the application shuts down. No-op for in-memory stores.
